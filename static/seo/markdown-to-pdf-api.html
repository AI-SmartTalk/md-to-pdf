Exemple : convertir un document Markdown

Chaque requête API utilise une clé propre au client dans l’en-tête X-API-Key. L’administrateur peut créer et révoquer chaque clé indépendamment.

curl https://pdf.aismarttalk.tech/api/convert \
  -H "X-API-Key: $MDTOPDF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Rapport\n\nRésultats du mois."}' \
  --output rapport.pdf

La clé doit rester côté serveur ou dans votre gestionnaire de secrets. Ne la placez jamais dans JavaScript livré au navigateur.
