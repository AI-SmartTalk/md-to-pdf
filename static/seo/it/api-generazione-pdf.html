Esempio: convertire un documento Markdown

Ogni richiesta API usa una chiave specifica del cliente nell’intestazione X-API-Key . Gli amministratori possono creare e revocare ogni chiave separatamente.

curl https://pdf.aismarttalk.tech/api/convert \
  -H "X-API-Key: $MDTOPDF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Report\n\nMonthly results."}' \
  --output report.pdf

Conserva la chiave sul server o in un gestore di segreti. Non inserirla mai nel JavaScript del browser.
