Domande frequenti

Serve un account?

Non serve un account per questa conversione rapida. L’accesso API richiede una chiave per proteggere le integrazioni e attribuire l’utilizzo.

Quali elementi Markdown sono supportati?

Titoli, paragrafi, elenchi, link, citazioni, tabelle e blocchi di codice comuni vengono convertiti in PDF.

Il PDF viene salvato dopo la conversione?

No. Questa pagina restituisce direttamente il PDF senza salvarlo nello spazio condiviso. Il motore di conversione potrebbe recuperare risorse esterne collegate nel documento.
