Comment convertir Markdown en PDF

  1. Collez ou écrivez votre document dans l’éditeur.
  2. Cliquez sur Créer mon PDF et attendez le rendu.
  3. Téléchargez le fichier PDF généré.

Le convertisseur accepte les titres Markdown, les listes, les tableaux, les citations, les liens et les extraits de code. Pour une mise en page à votre marque, une génération à partir de données ou un traitement automatisé, consultez l’API PDF pour développeurs.

Questions fréquentes

Faut-il créer un compte ?

Non pour cette conversion rapide. L’API complète demande une clé d’accès afin de protéger les intégrations et de suivre leur utilisation.

Quels éléments Markdown sont pris en charge ?

Les titres, paragraphes, listes, liens, citations, tableaux et blocs de code usuels sont convertis en PDF.

Le PDF est-il conservé après la conversion ?

Non. Cette page renvoie le PDF directement, sans sauvegarde dans le stockage partagé. Les ressources externes référencées dans le document peuvent être récupérées par le moteur de rendu.
