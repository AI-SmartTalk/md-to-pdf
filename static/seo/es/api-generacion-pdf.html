Ejemplo: convertir un documento Markdown

Cada solicitud a la API utiliza una clave específica del cliente en la cabecera X-API-Key . Los administradores pueden crear y revocar cada clave por separado.

curl https://pdf.aismarttalk.tech/api/convert \
  -H "X-API-Key: $MDTOPDF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Report\n\nMonthly results."}' \
  --output report.pdf

Guarda la clave en tu servidor o en un gestor de secretos. Nunca la incluyas en el JavaScript del navegador.
