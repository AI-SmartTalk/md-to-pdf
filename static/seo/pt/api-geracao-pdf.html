Exemplo: converter um documento Markdown

Cada pedido à API usa uma chave específica do cliente no cabeçalho X-API-Key . Os administradores podem criar e revogar cada chave de forma independente.

curl https://pdf.aismarttalk.tech/api/convert \
  -H "X-API-Key: $MDTOPDF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Report\n\nMonthly results."}' \
  --output report.pdf

Guarde a chave no seu servidor ou num gestor de segredos. Nunca a inclua no JavaScript do navegador.
