Beispiel: ein Markdown-Dokument umwandeln

Jede API-Anfrage verwendet einen kundenspezifischen Schlüssel im Header X-API-Key . Administratoren können jeden Schlüssel einzeln erstellen und widerrufen.

curl https://pdf.aismarttalk.tech/api/convert \
  -H "X-API-Key: $MDTOPDF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Report\n\nMonthly results."}' \
  --output report.pdf

Speichere den Schlüssel auf deinem Server oder in einem Secret-Manager. Binde ihn niemals in JavaScript im Browser ein.
