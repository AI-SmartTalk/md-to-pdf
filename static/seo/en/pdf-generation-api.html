Example: convert a Markdown document

Every API request uses a customer-specific key in the X-API-Key header. Administrators can create and revoke each key independently.

curl https://pdf.aismarttalk.tech/api/convert \
  -H "X-API-Key: $MDTOPDF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Report\n\nMonthly results."}' \
  --output report.pdf

Keep the key on your server or in your secrets manager. Never ship it in browser JavaScript.
